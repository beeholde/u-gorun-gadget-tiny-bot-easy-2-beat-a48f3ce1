A tiny paper-trading bot for hourly Solana bars: volatility-normalized trend scores rank the seven assets each hour, the strongest few are held under a basket-trend gate with stop and trailing exits, and cash is the default when no trend pays for its fees.

## Run it

```sh
node main.ts
```

The bot speaks the agent-fun/bars-replay/v1 line protocol on stdin/stdout: it reads the hello and each hourly batch, and answers every batch with its orders for the next open.
